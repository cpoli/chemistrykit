Reaction networks
-------------------

The general stoichiometric reaction-network engine: the steady-state
approximation and Lindemann's unimolecular fall-off, a chain-branching
explosion mechanism, Bateman's consecutive-reaction solution, Eigen's
relaxation kinetics, parallel reactions, and Gillespie's exact stochastic
simulation of the same networks.

For A \rightleftharpoons B the relaxation time is \tau = 1/(k_f + k_r), so combining \tau with the equilibrium constant K = k_f/k_r yields both rate constants. For the association A + B \rightleftharpoons C linearizing about equilibrium gives 1/\tau = k_f([A]_{eq} + [B]_{eq}) + k_r, the formula Eigen used to show that H^+ + OH^- recombination is diffusion-controlled.">
