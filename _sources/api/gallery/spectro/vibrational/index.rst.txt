Vibrational spectra
---------------------

Harmonic vs. Morse-potential IR band positions and anharmonicity
constants; Wilson GF-matrix normal modes for CO2 and H2O; the Raman/IR
mutual exclusion rule for CO2; and the doubly degenerate bend of a
linear triatomic.

The molecule&#x27;s geometry and masses give the kinetic-energy matrix G=BM^{-1}B^T, where B is the Wilson B-matrix. A diagonal valence force field gives the potential-energy matrix F. Solving the eigenvalue problem GFL=L\Lambda, with \lambda_k=(2\pi c\tilde\nu_k)^2, gives the normal-mode wavenumbers. Changing only the bend entry of F shifts the bend frequency, while the stretches barely move.">

A mode is Raman-active if it changes the molecule&#x27;s polarizability. It is infrared-active if it changes the dipole moment. For a centrosymmetric molecule such as CO2, no mode is active in both spectra.">

A nonlinear molecule of N atoms has 3N-6 vibrations. A linear molecule has 3N-5, because rotation about its axis does not count as a degree of freedom. For CO2 this means four vibrations: the symmetric stretch, the antisymmetric stretch, and a doubly degenerate bend (in-plane and out-of-plane bending have the same frequency by cylindrical symmetry). This example compares linear CO2 with bent H2O using TriatomicNormalModes, whose is_linear flag marks the bend as a degenerate pair.">
