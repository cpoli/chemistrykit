    <div class="sphx-glr-thumbcontainer" tooltip="Tafel (1905) found that far from equilibrium the overpotential of hydrogen evolution grows linearly with \log_{10} i: \eta = b\log_{10}(i/i_0). This example generates noisy &quot;measured&quot; high-overpotential data, draws the Tafel plot, and uses fit_tafel_plot to recover the Tafel slope b and exchange current density i_0 by linear regression -- the analysis Tafel&#x27;s successors still use, and compares the slope with tafel_slope&#x27;s textbook ~118 mV/decade for \alpha = 0.5, n = 1.">

At zero overpotential the two partial currents are equal (each is i_0) and cancel -- a dynamic equilibrium; far from equilibrium one term dominates and the equation becomes Tafel&#x27;s straight line. This example plots both partial currents and butler_volmer_current_density, shows the effect of the transfer coefficient \alpha, and checks numerically how fast the Tafel limit is reached.">
